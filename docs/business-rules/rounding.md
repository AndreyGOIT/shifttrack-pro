Business Rule BR-001: Time Rounding

Status

Accepted

⸻

Purpose

To provide consistent payroll calculations while preserving the original recorded timestamps for auditing purposes.

Raw timestamps must never be modified.

Rounded timestamps are used only during payroll calculations.

⸻

Rule

Working time is rounded up to the next 15-minute interval.

The rule applies to both:

- work start time
- work end time

⸻

Examples

Raw Time Rounded Time
07:00 07:00
07:01 07:15
07:07 07:15
07:14 07:15
07:15 07:15
07:16 07:30
17:07 17:15
17:46 18:00

⸻

Raw vs Rounded Time

The system stores two different concepts.

Raw Time

Represents the actual recorded timestamps entered by the employee.

Example:

Start: 07:03
End: 17:07

Raw values are immutable.

⸻

Rounded Time

Generated by the Calculation Engine.

Example:

Start: 07:15
End: 17:15

Rounded values are used for payroll calculations only.

⸻

Design Rationale

Separating raw and rounded timestamps provides:

- accurate audit trail
- transparent calculations
- configurable payroll policies
- future support for organization-specific rounding rules
