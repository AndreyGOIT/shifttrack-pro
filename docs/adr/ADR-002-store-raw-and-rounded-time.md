ADR-002: Store Raw and Rounded Time Separately

Status: Accepted

Date: 2026-07-14

⸻

Context

Payroll calculations require consistent and predictable time values.

At the same time, organizations must preserve the original timestamps entered by employees for auditing and compliance purposes.

Using only rounded values would result in loss of information.

Using only raw values would make payroll calculations inconsistent across organizations.

⸻

Decision

ShiftTrack Pro will maintain two distinct representations of time:

- Raw Time
- Rounded Time

Raw timestamps will always be preserved.

Rounded timestamps will be generated by the Calculation Engine and used exclusively for payroll calculations.

⸻

Examples

Raw Time Rounded Time
07:00 07:00
07:07 07:15
17:07 17:15
17:46 18:00

⸻

Consequences

Advantages

- Complete audit trail
- Transparent payroll calculations
- Configurable rounding policies
- Easier debugging
- Future support for organization-specific rules

⸻

Trade-offs

- Additional calculation step
- More complexity in the domain model

These trade-offs are acceptable because auditability and maintainability are considered primary requirements.

Related Documents

⸻

Future Considerations

Future versions may support:

- 5-minute rounding
- 15-minute rounding
- nearest interval rounding
- organization-specific policies
- country-specific payroll rules
